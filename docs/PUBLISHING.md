# 源码上传范围

用户要求模型、密钥及关键本地资料不上传。此仓库采用以下范围：

- 允许：独立应用源码、源码检查脚本、锁定的前端依赖清单、Python依赖清单、说明与第三方许可。
- 界面资源的唯一二进制例外：`app/src/fonts/fusion-pixel-12-ui.woff2`。它是Fusion Pixel的OFL字体子集，随同目录的`fusion-pixel-OFL.txt`发布。上传检查锁定这份字体的SHA256、WOFF2格式和大小，并要求暂存区内包含匹配的许可；其他字体或二进制不因此获得许可。
- 排除：全部角色原画、模型运行文件和纹理，Cubism Core运行库，Textractor及其他取词二进制工具，旧参考项目，API密钥、本地配置、用户聊天记录、剧情原文与SQLite数据库、日志、缓存、截图、音频和归档包。
- `.env.example` 只保留空凭据与不可用的示例地址；真实参数仅在 `.env.local` 或 `.yuki.local.json`。界面保存的配置采用后者，两者均不得上传。
- `.gitignore` 默认拒绝根目录新内容，只允许列出的源码路径。不得用 `git add -f` 绕过排除规则。

每次推送前，用项目Python运行 `scripts/audit_upload.py`。它检查实际暂存内容，扫描本地已配置的密钥值和常见令牌格式，不输出密钥；获准的字体也继续参与密钥检查。检查失败时先移出相关文件，再提交。

此检查可减少误上传，不能替代对新增文件的审阅。不要把日志、聊天内容或其他配置文件改名后放进允许上传的源码目录。
