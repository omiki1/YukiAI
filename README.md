# YukiAI · 一起看剧情的朋友

Yuki 是一个面向中文 Galgame 和小说的桌面共读助手。玩游戏时，她以小窗口和单条气泡陪在旁边；需要讨论时，可以一起回想台词、分析人物动机、追踪伏笔，以及解释中文译文里的文化典故。

项目仍处于 Alpha 开发阶段。当前仓库提供源码和本机构建方法，**尚未公开正式 Release 下载包**。仓库不包含私人角色模型、API 密钥和阅读资料；没有模型也可以使用纸签界面完成聊天与共读。

## 目前可以做什么

| 功能 | 用法 |
| --- | --- |
| 紧凑桌面小窗 | 默认 320×460，最小 280×380；操作栏触碰角色时出现，聊天气泡可以收起 |
| 游戏连续取词 | 选择游戏，核对正文来源后记录后续台词；收起小窗后继续记录 |
| 按键定位当前剧情 | `Ctrl+Alt+Y` 读取选定游戏的文字区域，在已有台词中匹配位置，再准备讨论 |
| 小说共读 | 按已读章节、段落收录，保留自己的阅读位置 |
| 故事脉络与人物 | 浏览原文卡片、人物说辞、选项、章节；按关键词、类型和说话者筛选 |
| 共读记忆 | 保存原文、讨论、书签、路线、疑问和人物称呼纠正，重启后接着读 |
| 本机记忆管理 | 预览后清理讨论或共读，备份、恢复副本、删除备份、整理空间 |
| 自选接口与外观 | OpenAI 兼容聊天接口；五种主题，默认像素风；可选 Fish Audio / OpenAI 兼容语音 |

完整游戏脚本导入、整部剧本的路线索引、游戏存档自动识别和跨周目记忆尚未实现。连续取词只记录开始后出现的新台词，按键定位只查找已经记录的当前路线内容。

## 安装与启动

### 方式一：Windows 源码版

准备 Python 3.12 或更新版本、Node.js（含 npm）和 Git。在终端中执行：

```powershell
git clone https://github.com/omiki1/YukiAI.git
cd YukiAI
.\setup_yuki.cmd
```

也可以下载仓库源码 ZIP，解压后双击 `setup_yuki.cmd`。准备脚本会建立项目内 `.venv`、安装依赖并构建界面。完成后双击 `start_yuki.cmd` 启动。

想手动准备环境，可以依次执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd app
npm ci --ignore-scripts
npm run check
npm run build
cd ..
.\.venv\Scripts\python.exe start_yuki.py
```

没有角色素材时会使用内置纸签界面。**正常使用聊天、手记和记忆管理不需要先准备 Live2D。** 游戏取词和按键读屏需要 Windows 桌面版。

### 方式二：自己构建免安装包

项目包含 Windows 免安装 Alpha 的构建脚本，方法见后文[开发、检查与构建](#开发检查与构建)。构建产物需要完整解压，之后双击 `YukiAI.exe`；不能只复制一个 exe。包内包含 Python、Qt 和界面，接收者无需另装 Python 或 Node.js。

免安装 Alpha 使用纸签界面，不带私人模型、Cubism Core、取词工具、接口配置或阅读资料。当前没有正式公开的现成发行包，也没有完成干净 Windows 环境与真实玩家的全面验收。

### 可选：使用自己的 Live2D 模型

源码版可将自行持有的运行素材放入以下位置，然后重新构建界面：

```text
app/public/model/yuki_cutout.model3.json
app/public/model/模型引用的其他运行文件
app/public/vendor/live2d-core/live2dcubismcore.js
```

模型入口需要与程序约定的文件名一致，相关纹理、MOC、表情等路径需完整。素材和 Core 须自行合法取得；不随本仓库分发。缺失或初始化失败时回退到纸签界面。

## 第一次使用与窗口操作

1. 启动后点击桌面上的 **Yuki** 小按钮展开窗口；再次点击可收起。收起窗口后，已经开始的取词仍可继续。
2. 鼠标移到角色可见部分，操作栏会在角色上方出现。点 **⚙** 打开设置，点 **▤** 打开剧情记录；拖动操作栏的 **Yuki** 区域移动窗口。
3. 点气泡里的 **聊聊** 输入问题，发送后收起输入框。回复逐字显示，点击文字可立即显示完整内容，长消息可点 **展开**。
4. 气泡的 **···** 提供回想、新聊、使用引导和收起气泡。收起气泡会保留草稿和回复；点击小标签可以重新展开。
5. **设置 → 外观** 可切换像素、磨砂玻璃、纸本、霓虹和经典主题，或调整角色大小。主题选择在本机记住。

首次未配置聊天且没有共读时，会显示使用引导。可以先展开 **体验示例**，读完三句自编故事，再点击 **已读完，开始体验**。这会建立独立的示例共读，不会调用聊天接口。之后开始自己的游戏或小说时，请另外建立新共读。

像素主题的回复字体可单独关闭。公开源码自带经过许可核对的 UI 字体子集，未覆盖的字使用系统字体；本机可选的完整中文字体不上传，缺少它也可以正常构建。

## 配置聊天接口

入口：**⚙ → 聊天接口**。

| 字段 | 填写内容 |
| --- | --- |
| 接口地址（Base URL） | 服务商给出的 OpenAI 兼容基础地址，通常以 `/v1` 结尾；不要自行拼成完整聊天请求地址 |
| API Key | 你自己的服务密钥；本机接口支持留空，外部接口需填写 |
| 模型名称 | 服务控制台提供的完整模型 ID，不要填写昵称 |
| 请求 JSON 格式回复 | 默认勾选；服务不接受该选项时可取消 |

点 **保存设置** 只保存配置。点 **保存并测试聊天** 才会发送一句测试问候；成功后就可以从气泡发送问题。外部服务使用 HTTPS，本机 `localhost` 等地址支持 HTTP。

已有密钥不会回填到界面：留空表示保留；勾选清除并保存才会删除。配置保存在本机 `.yuki.local.json`，优先于旧 `.env.local`。也可以参照 `.env.example` 在本机填写配置，但不要提交真实文件。

聊天时，程序会挑选当前已读范围内的相关台词、人物索引、近期讨论和手记交给所配服务，**不会每次发送整部剧情**。回复旁出现 **依据** 时，可以打开引用的原句。材料和引用经过范围检查，推断仍需结合原文判断，不能保证完全没有误解或剧透。

## Galgame：连接游戏并持续记录

这一步让 Yuki 在你游玩时积累台词。它与唤醒、提问分开运行，不需要为了记录每句话反复叫出助手。

1. 先启动游戏。打开 **▤ → 新共读**，选择 **Galgame**，填写游戏名和共读名；建议不同游戏、周目分别建立记录。
2. 在 **游戏共读** 点 **连接游戏**，进入连续取词页。也可以直接打开 **连续取词**。
3. 第一次使用时点 **准备取词工具**。程序从官方固定版本下载 Textractor 并校验文件；完成下载还不会自动连接游戏。预览模式不下载安装。
4. **刷新游戏**，从列表选中要玩的游戏窗口，点 **连接游戏**。只有这次点击会连接/注入所选进程。没有当前共读时，连接成功会按窗口名称建立一篇游戏记录；已有共读不会被自动替换。
5. 回到游戏推进一句台词，再到 Yuki 选择 **正文来源**。确认预览与游戏台词一致，避开菜单、快捷键提示和单独的姓名来源。
6. 勾选 **以上预览是我正在阅读的游戏正文**，点 **确认台词并开始记录**。看到正在记录及句数变化后，即可收起面板继续游戏。

记录的是开始后新出现的台词，旧预览不会自动补入。程序会过滤短时间重复输出、合并逐字增长文本，并保留正常出现的重复台词。取词不会自动提问或朗读。

姓名与正文分开、识别不到正文时，可以展开 **识别设置与手动 Hook 码** 调整类型、指定说话者或添加已知的 H/R 码。这里不提供自动内存搜索，也不自动提权。不同引擎、游戏版本和汉化补丁需要实际验证，尚无完整的游戏兼容清单。

**读档前先暂停取词。** 在书签页恢复对应进度后，再核对并开始记录。Yuki 内切换共读、路线或阅读位置会暂停取词；关闭程序会断开连接，下次启动需重新连接。

取词工具来自 [Textractor 官方项目](https://github.com/Artikash/Textractor)，当前安装器固定官方 5.2.0 便携版并核对 SHA256，只保留所需 x86/x64 CLI、DLL 和运行库，放在本机 `tools/textractor/`。仓库不携带这些二进制文件。

## Galgame：按快捷键定位剧情

已经记录了台词后，可以用当前画面找回所在场景，再接着讨论。

1. 打开 **▤ → 游戏共读 → 选择游戏与文字区域**。
2. 选择要读取的游戏窗口，在它的预览中框住姓名和当前台词。尽量只选文字区域。
3. 回到所选游戏，按 **Ctrl+Alt+Y**。Yuki 会读取该区域，用 Windows 本地中文 OCR 识别，再匹配当前路线已经保存的台词。
4. 核对识别文字；有误可直接修改并点 **重新匹配剧情**。出现多个候选时，选择正确位置。
5. 按需填写想聊的问题，点 **定位并准备聊天**，再从气泡发送。没有匹配时，可核对后补记当前片段，再准备问题。

识别图片仅在内存中处理，不上传、不保存截图，也不自动改用全桌面截图。需要 Windows 中文 OCR 语言包；独占全屏或部分 GPU 游戏可能读到黑屏，可尝试窗口或无边框模式。切换游戏、重启程序或窗口画面比例改变后，需要重新选择区域。

匹配到已记录台词时复用原文，不重复收录；确认更早的位置会按回看处理，并暂停取词。在普通聊天或小说共读中，同一快捷键只展开输入，不读取游戏画面。

**很久不唤醒会不会断片？** 只要有效的连续取词一直运行，新台词就会继续积累，之后可按当前画面匹配已有记录。未开启记录、来源无效或中途漏掉的文字不会凭空补齐。整部游戏脚本导入和路线索引仍待开发。

## 小说与手动收录

入口：**▤ → 新共读 → 读的是：小说**。填写小说名后，进入 **收录**。

1. 粘贴已经读过的章节或段落。每行记录为一段，空行跳过；输入框默认留白。
2. 选择内容类型；小说章节标题、人物说话和旁白会按规则整理。也可以手动指定对白、旁白或选项。
3. 勾选 **这些内容我已经读过**，点 **收录并更新进度**。
4. 回到气泡讨论，或从 **原文、目前记得、脉络** 回看相关内容。

单次最多 200 行、60000 字，单行最多 2000 字。这里不是整书文件上传或未读全文索引入口，请按已读部分收录。小说模式不注入游戏、不按快捷键读屏。

Galgame 取词不可用时，也可在 **连续取词 → 手动收录** 粘贴已读台词。手动格式可用 `人物名：台词`、`旁白：描述` 或选项文本；收录和整理原文本身不调用模型。

## 书签、回档与分支

入口：**▤ → 书签与路线**。

- 到选项或重要进度时先 **留书签**，名称可以写成便于对应游戏存档的说明。
- 游戏读档前暂停取词，随后在 Yuki 找到对应书签点 **回到这里**，或在原文旁点 **读到这里** 校准。
- 回退后收录不同内容会另存新路线，原路线保留；也可以从当前位置主动开启另一条路线。
- 切换路线会前往该路线已记录的末尾。回档或切线会停止当前回复与朗读，之后按新的阅读范围讨论。

游戏存档与 Yuki 记录目前需要手动对应。Yuki 不会自动识别存档槽、选择结果或你在游戏里进行了哪次读档。

## 脉络卡片、手记与人物

### 看故事脉络

打开 **▤ → 脉络**，已读原文会整理为片段、人物说辞、选项、章节及玩家手记卡片。

- 在 **筛选卡片** 按类型、说话者或关键词查找。
- **看原文** 打开完整关联原句；**记个想法** 保存疑问、猜测或感受。
- **一起聊** 只准备讨论草稿，由你点击发送。

卡片按阅读顺序排列，连线不代表故事中的真实时间或因果。人物说辞、玩家猜测和原文叙述保留不同标记。浏览与筛选不调用聊天服务。

### 接着上次读、保留想法

打开 **▤ → 原文 → 接着上次读 / 共读手记**。

回顾展示当前进度内的原句摘录和最近讨论的问题。可以从讨论话题 **留作疑问**，或手动写一条手记并关联当前原文；支持修改、标记已聊清楚和确认删除。每条最多 800 字。

手记会进入后续相关讨论，回档时只使用当时可见的版本；子路线继承建立分支时已有的相关内容。**已聊清楚** 是个人标记，不会把猜测变成剧情事实。新聊保留手记，删除共读会一并清理；删除单条手记会删除各路线中的全部版本。

### 纠正人物与称呼

打开 **▤ → 原文 → 人物与称呼 → 纠正人物对应**，选择称呼或这句的“她/他”，填写已读人物，核对关联原文并勾选后保存。

称呼纠正从当前位置起随路线使用；单句指代仅在对应句子的讨论中生效。纠正不改写原台词，也不证明隐藏身份。支持修改、旧版本、查看原文和确认删除，备份可恢复这些记录。

## 记忆备份与清理

入口：**▤ → 记忆管理**。可查看各次共读、旧讨论、普通聊天、备份及本机占用。

| 操作 | 影响范围 |
| --- | --- |
| 新聊 | 开始新的讨论，保留已读原文、旧讨论、手记和人物纠正 |
| 清空讨论 | 删除所选共读所有路线和旧讨论；保留原文、进度、路线、书签、手记和人物纠正 |
| 删除共读 | 删除这篇共读及其原文、路线、书签、讨论、手记等；其他共读保留 |
| 备份全部记忆 | 将共读和普通聊天保存为本机快照；不包含密钥、接口配置、模型和取词工具 |
| 恢复副本 | 校验后建立独立副本，原有记录保留；普通聊天副本可从列表继续聊 |
| 删除备份 | 单独删除选定备份；清理原记录不会自动删除已有备份 |
| 整理空间 | 回收数据库空闲空间，保留有效记录；不是安全擦除 |

删除、恢复等操作会先预览影响范围，再勾选确认；记录变化或预览过期后需重新预览。影响阅读范围的清理会停止旧回复与朗读、暂停取词。系统没有回收站，需要恢复能力时请先备份。

### 数据放在哪里

| 数据 | 源码版默认位置 |
| --- | --- |
| 接口、密钥和角色大小 | `.yuki.local.json` |
| 共读原文、路线、进度、讨论、手记 | `data/story.sqlite3` |
| 普通聊天 | `chat_history/` |
| 本机备份 | `data/memory_backups/` |
| 取词工具 | `tools/textractor/` |

源码版使用项目目录；免安装版默认将个人资料放在 `%LOCALAPPDATA%\YukiAI`。启动参数 `--data-dir 目录` 可指定独立资料位置。更新程序不会自动清空阅读记录；移走源码版项目前应备份，迁移时保留完整资料。

配置、备份和阅读资料是本机明文文件，请自行保管。仓库采用源码上传白名单，这些个人文件均排除在 Git 之外。原文保存在本机；主动发送问题时，相关片段会交给你所配的聊天服务；开启语音后，待朗读文字会交给语音服务。

## 可选语音

语音默认关闭，不影响共读功能，后续开发优先级暂缓。入口：**⚙ → 语音接口**。

- **Fish Audio**：填写完整合成地址、自己的密钥、所选模型和可选音色 ID；音色留空使用服务默认值。不自动切换付费模型。
- **OpenAI 兼容语音**：填写基础接口地址、密钥、语音模型和音色；程序追加 `/audio/speech`，当前需要 WAV 返回格式。
- 点 **保存并试听** 明确发起一次试听；勾选自动朗读后才朗读聊天回复。可随时点 **停声**。

聊天先得到完整文字并检查阅读范围，再按短句合成与播放：首段就绪后开始，播放时最多准备下一段。当前不是逐字音频流。每段可能是一次服务调用，费用由服务方规则决定；停止、发送新消息或改变阅读范围会取消后续片段。语音失败保留文字，过长回复只显示文字。

项目没有麦克风录音、语音识别或摄像头功能。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 启动后只看到小按钮 | 点击 Yuki 展开窗口；操作栏需鼠标触碰角色后显示 |
| 没有立绘，显示纸签 | 公开源码未携带私人模型，这是可用的回退界面；可自行配置模型 |
| 收录原文后没有自动回复 | 收录只保存；点聊聊或准备问题后发送，才调用聊天接口 |
| 点测试连接失败 | 核对 Base URL、完整模型 ID、密钥和服务额度；服务不支持 JSON 选项时取消该选项后再试 |
| 连接游戏后没有正文来源 | 推进新台词并刷新核对；需要时用已知 Hook 码，或使用按键读取、手动收录 |
| 预览是菜单或只有名字 | 更换正文来源；不要在错误来源上确认记录 |
| 快捷键没有读到文字 | 确认是桌面版 Galgame 共读、已选游戏和文字区域，切回所选游戏再按键；检查快捷键冲突 |
| OCR 提示缺少语言包或读到黑屏 | 准备 Windows 中文识别语言包；尝试窗口/无边框模式，重新框选文字区域 |
| 读档后剧情对不上 | 先暂停，再恢复对应书签或读到这里，核对后重新开始取词 |
| 想找助手未记录的剧情 | 当前无法从完整剧本补齐；需已有有效取词记录，或核对后手动补记 |
| 端口被占用 | 退出另一个 Yuki；诊断时可通过 `--port` 指定其他本机端口 |
| 免安装包在中文目录启动失败 | 完整解压到英文路径，例如 `C:\YukiAI`；部分磁盘无法提供 Qt 所需的兼容路径 |

没有自动读取剪贴板、后台全桌面截屏、自动操作游戏或自动联网查攻略。按键读屏由用户显式触发，只针对选定游戏区域。

## 开发、检查与构建

### 常用命令

以下命令在仓库根目录执行；`python` 应指向准备好的 Python 环境。

```powershell
# 只读检查：不调用云服务、不创建阅读记录
python start_yuki.py --check

# 预览：禁止外部模型调用
python start_yuki.py --mode preview

# 只启动本机网页服务，默认 http://127.0.0.1:12393/
python start_yuki.py --headless --mode preview

# 独立资料目录
python start_yuki.py --data-dir C:\YukiData

# 离线后端检查
python -m unittest scripts.test_window_backend scripts.test_window_settings scripts.test_story_memory scripts.test_capture scripts.test_memory_management scripts.test_continuity scripts.test_characters scripts.test_timeline scripts.test_game_reading scripts.test_delivery

# 检查实际暂存区的上传范围、密钥和资源
python scripts/audit_upload.py
```

浏览器预览可检查界面、聊天和记录；游戏选择与文字区域框选依赖桌面原生桥接，不能把网页预览当成完整桌面功能。

构建前端后，可运行自带隔离服务的浏览器验收，例如：

```powershell
node scripts/verify_themes.cjs
node scripts/verify_game_reading.cjs
node scripts/verify_capture_setup.cjs
node scripts/verify_timeline.cjs
node scripts/verify_memory.cjs
node scripts/verify_continuity.cjs
node scripts/verify_characters.cjs
node scripts/verify_speech_queue.cjs
node scripts/verify_speech_latency.cjs
```

这些验收使用自编文本与本机替身服务，不调用真实云模型。需本机安装 Chrome，或按脚本支持的环境变量指定浏览器。原生 OCR、真实取词及部分历史界面验收另有环境要求，见脚本说明；样例通过不等于所有游戏兼容。

### Windows 免安装 Alpha 构建

在 Windows 的独立 Python 3.12 构建环境安装 `requirements-build.txt`，先在 `app/` 准备 npm 依赖，再于根目录执行：

```powershell
python -m scripts.build_alpha
```

产物在 `artifacts/alpha-编号/`，包含完整程序目录和 `YukiAI-Windows-Alpha.zip`。构建只使用明确输入，扫描私人资料与本机已配置密钥，附带依赖版本和许可。产物不进入源码提交。公开发行还需补齐许可证安排、具体游戏兼容验证和真实玩家体验验证。
